ECT Blog Admin Guide

This map explains where every article value appears and which values are generated automatically.

Add a new blog

Recommended publishing workflow

  1. Create a draft and add the title, category and article content.
  2. Use one H2 for every main section. The public table of contents is generated from H2 headings.
  3. Select existing tags with search. Create a missing tag using the add button.
  4. Add a hero image and descriptive alternative text.
  5. Review the live SEO checklist and run “Check article links”.
  6. Open Preview article, check desktop/tablet/mobile, then move through review and publish.

Article fields

FieldPurposeAutomation
TitleThe public H1, listing-card title and main article name.Used to suggest the slug, SEO title and social title.
SlugThe URL after /blog/.Generated from the title; old slugs redirect after a change.
CategoryMain topic used by blog-page filters.Only categories containing visible blogs appear publicly.
TagsSupporting topics. Search and select existing tags; create a tag only when required.Tag slugs are generated automatically.
Related blogsManual related-article choices.Any empty slots are filled from the same category and then other published blogs.
Hero descriptionListing excerpt and introduction below the article H1.Used as the first meta-description suggestion.
Article contentParagraphs, H2–H6, lists, links, images, tables, quotations and code.Sanitized, internal URLs normalized, H2 IDs/TOC, image dimensions and reading time generated.

Author and trust

Ragupathi Namachivayam is automatically supplied as the default author with designation, biography, photo and profile URL. Every field remains editable for an individual article. “Reviewed by” and “Last reviewed at” add editorial trust information.

SEO and social fields

FieldHow to use it
Primary keywordMain search topic. Include it naturally in the title, description and content.
Secondary keywordsComma-separated supporting topics; do not force every phrase into the article.
Search intentChoose informational, commercial, transactional or navigational.
Meta title/descriptionGenerated when empty and always editable. Keep the title near 60 characters and description near 160.
Canonical URLGenerated from the production domain and slug; edit only for intentional duplicate-content handling.
Open Graph/TwitterGenerated from SEO fields when empty; customize for social sharing if needed.
Robots and sitemapControl indexing, link following, sitemap inclusion and priority.
SchemaBlogPosting, Person/Organization and breadcrumb schema are generated on the public page.

Publishing and maintenance

Status controls the workflow: Draft → SEO Review → Content Review → Approved → Published, with Scheduled for future publishing. Reading time is automatic unless “Auto reading time” is turned off; updated date is automatic. Views are informational. Comments require approval before they appear publicly. Revisions preserve saved article states and can be restored.

Important: Images are files in media/, while their references and article text are saved in the database. Back up both the database and media directory before deployment or migration.
